# Гаманець — особисті фінанси

Мобільний PWA-застосунок для обліку особистих фінансів у стилі Liquid Glass. Українською, у гривнях (₴).

## Структура проєкту

```
wallet-app/
├── index.html              точка входу, підключає всі стилі й скрипти
├── manifest.json            PWA-маніфест (іконка, назва, тема)
├── css/
│   ├── theme.css             CSS-змінні, кольори, скидання стилів, типографіка
│   ├── background.css        анімовані світлові плями фону, контейнер #app
│   ├── components.css        скляні картки, баланс, кнопки, рядки транзакцій, нижня навігація
│   ├── modal.css              модальне вікно додавання/редагування, поле суми, вибір категорії
│   └── misc.css               тости, статистика (діаграма), налаштування, діалог підтвердження
└── js/
    ├── icons.js               іконки (inline SVG)
    ├── categories.js          6 категорій витрат: назва, колір, іконка
    ├── utils.js                форматування грошей/дат, генерація id, екранування HTML
    ├── state.js                глобальний стан застосунку (state) та стан інтерфейсу (ui)
    ├── storage.js              завантаження/збереження даних (window.storage → localStorage)
    ├── selectors.js            похідні дані: баланс, суми, фільтр за періодом
    ├── render-app.js           головний render(), перемикання теми, обгортка іконки
    ├── render-home.js          екран «Головна»
    ├── render-history.js       екран «Історія» з фільтрами
    ├── render-stats.js         екран «Статистика» (донат-діаграма)
    ├── render-settings.js      екран «Налаштування»
    ├── modal.js                модальне вікно додавання/редагування витрати чи прибутку
    ├── confirm-toast.js        діалог підтвердження видалення + спливаючі повідомлення
    ├── ui-events.js            підключення обробників подій до поточного екрана
    └── app-init.js             ініціалізація застосунку при завантаженні
```

## Як запустити

Просто відкрийте `index.html` у браузері (найкраще — у вузькому вікні чи на iPhone,
або через локальний сервер, наприклад `npx serve .`).

## Збереження даних

- У середовищі Claude.ai (як артефакт) дані зберігаються через вбудоване сховище `window.storage`.
- Поза Claude.ai (якщо відкрити файл самостійно чи розмістити на власному хостингу)
  застосунок автоматично використовує `localStorage` браузера — дані так само не зникають
  після оновлення сторінки.

## Технології

Без збірників і фреймворків — чистий HTML/CSS/JavaScript (ES2020+), щоб проєкт можна було
відкрити й редагувати без додаткових інструментів.
